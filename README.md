## Prasyarat

- [Node.js](https://nodejs.org) v20 atau lebih baru (dikembangkan dengan v24)
- npm (sudah termasuk saat install Node.js)

## Cara Menjalankan

```bash
# 1. Clone repository
git clone https://github.com/almaas-izdihar/landing-page-77c.git

# 2. Masuk ke folder project
cd landing-page-77c

# 3. Install dependencies
npm install

# 4. Jalankan development server
npm run dev
```

Setelah `npm run dev` berjalan, buka alamat yang tampil di terminal (biasanya http://localhost:5173).

## Perintah Lain

| Perintah | Keterangan |
|----------|------------|
| `npm run dev` | Menjalankan development server dengan hot reload |
| `npm run build` | Build versi production ke folder `dist/` |
| `npm run preview` | Menjalankan preview hasil build production |
| `npm run lint` | Menjalankan ESLint |
